# This is NOT the Next.js you know

This project uses Next.js `^16.3.5` and React `^19.3.0`. These versions introduce significant breaking changes from previous Next.js versions.

## Key Information for Agents:

*   **Next.js Documentation:** Always consult `node_modules/next/dist/docs/` for up-to-date API references and conventions.
*   **Development Server:**
    *   `npm run dev`: Starts the development server.
*   **Build & Start:**
    *   `npm run build`: Builds the application for production.
    *   `npm run start`: Starts the production server.
*   **Linting:**
    *   `npm run lint`: Runs ESLint for code quality checks.
*   **Core Technologies:** Next.js, React, TypeScript, Sanity.io (CMS), `next-intl` (i18n), Tailwind CSS, Framer Motion, Embla Carousel, Vaul, Radix UI.
*   **Main Entry Point:** The primary page for editing is `app/page.tsx`.
*   **Path Aliases:** Use `@/` for absolute imports from the project root (e.g., `import Component from '@/components/Component'`).
